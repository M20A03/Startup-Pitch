## Key Features

- **Slide-by-slide pitch walkthrough:** Keyboard arrow and swipe navigation.
- **Financial modeling calculator:** Real-time CAC, LTV, MRR, and ARR forecast sliders.
- **Animated reveals:** Smooth transitions with viewport triggers.
- **Investor resources:** Term sheet request modal and summary memos.
- **Branding:** Modern, high-contrast palette with Cyber Tangerine (#FF5722) and Deep Navy (#0F172A).

---

## Spatial Web and Mobile Viewport Specifications

- **Precision Viewport Scaling:** Seamless responsive adaptation from vertical mobile story layout (360px-430px) to widescreen presentation mode.
- **Touch Ergonomics:** Standard 48px minimum interactive tap boundaries across all buttons and inputs.
- **Hardware Acceleration:** Zero image-layout shifts, GPU-accelerated micro-animations, and fluid 60fps transitions.
- **Safe Area Inset Handling:** Dynamic insets accommodating modern mobile displays.

## Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher)
- Git installed on your system

### Installation and Run

```bash
git clone https://github.com/M20A03/Startup-Pitch.git
cd Startup-Pitch
npm install
npm run dev
```
