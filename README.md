Interactive pitch presentation platform built for founders, featuring dynamic slide navigation, investor traction metrics, interactive unit economics, and Framer Motion reveals.

## ✨ Key Features

- **Dynamic slide-by-slide pitch walkthrough with keyboard arrow and swipe navigation**
- **Interactive financial modeling calculator:** CAC, LTV, MRR, and ARR forecast sliders
- **Framer Motion animated reveals with Intersection Observer viewport triggers**
- **Downloadable one-pager investor memo and term sheet request modal**
- **High-contrast startup branding with Cyber Tangerine (#FF5722) and Deep Navy (#0F172A)**

- Node.js (v18.0.0 or higher) / Python 3.10+ (where applicable)

```bash
cd Startup-Pitch
npm install
npm run dev
```
